# Flood-Forecast-Intelligence
Varuna: A small-area operational digital twin that estimates which streets may be affected by heavy rain and compares possible response actions.

## Project specifications

- [Product Requirements Document](Product%20Requirements%20Document.md) — scope, users, acceptance criteria, and demo story
- [Architecture](Architecture.md) — data, AWS services, scoring, routes, and APIs
- [Agents](Agents.md) — bounded AI behavior and repository implementation rules
- [Design System](Design-System.md) — visual tokens, layouts, components, and accessibility

The pilot is a decision-support prototype. Its risk classes and intervention outcomes are estimates, not verified street-level flood forecasts.
